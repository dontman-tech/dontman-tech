### 🌟 Selected Work

- **🎙️ ARIA** — A voice assistant that answers offline and escalates to the cloud only when it must. Python brain + Kotlin Android bridge, 14 modular skills, 4 LLM backends, and a kill switch that halts everything at once.
- **📱 Phoney** — Phone Link for Linux over the KDE Connect protocol: notifications, file transfer and clipboard sync, plus SMS, calls, battery, find-my-phone and scrcpy mirroring. TLS pairing verified end to end, zero-dependency web dashboard, tagged v0.1.0.
- **♻️ Re-kollect** — A two-role Flutter marketplace for waste pickup where no system owns the last mile: geofenced confirmation (50 m location log), two-sided job verification, reliability scores, and dispatch to nearby collectors.
- **🏃 Pulse Fit** — A cross-platform fitness tracker with 5 curated workout plans, animated activity rings, and two-way Apple HealthKit / Google Fit sync. React Native + Expo + Reanimated.
- **✋ Air Canvas** — Draw in the air with your finger: webcam hand landmarks mapped onto a 5-state gesture machine with a 6-colour palette. The smallest project I've built and the one that taught me the most about latency.
- **🎲 Who Is Most Likely To** — A realtime party game where everyone joins by room code: codes skip look-alike glyphs, countdowns run off the server clock, and votes stay secret until the reveal. React + Vite + Upstash Redis.
- **✨ Lumina** — An AI request-routing pipeline architected and deployed in 15 hours with a 3-person team, degrading gracefully under rate limits. Placed at the Prometheus AI Hackathon.
- **🔐 NESAC** — A password strength checker that doesn't just score a password, it explains each weakness in plain language and suggests a stronger passphrase. Python + Flask.
- **🔎 Spark** — An AI-powered browser that centralises smart search, Wikipedia lookups, live weather and current news into a single interface.

### ⚙️ How I Work

- **Degrade, don't break.** No microphone? Fall back to text. No API key? Fall back to a deterministic offline mode. A user should never meet a dead end because one dependency was missing.
- **Route before you generate.** "Turn on the flashlight" is a command, not a prompt. Match on rules first, reach for a model only when nothing matches — faster, cheaper, works offline.
- **Ship to the device.** A repo is not a product. Everything I build has to run on hardware a normal person actually owns.
